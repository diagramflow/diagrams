# Decision Records

## Purpose

This index owns repository-local architectural decisions for the public
`diagrams` distribution.

## Current Decisions

No standalone ADR is active. The current ownership and compatibility decisions
are canonical in [Upstream provenance](/UPSTREAM.md) and
[Maintenance](/docs/maintenance.md).

Create an ADR here only when a durable choice cannot be expressed as an update
to those current contracts. Completed or replaced ADR history belongs in Git
after its still-relevant knowledge has been migrated.
